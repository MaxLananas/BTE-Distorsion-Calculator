Fondements théoriques

BuildTheEarth utilise une projection conforme icosaédrique modifiée, dérivée de la projection Dymaxion de Buckminster Fuller. La modification conforme est réalisée via une transformation de Schwarz-Christoffel, qui préserve les angles locaux au détriment d'un facteur d'échelle local variable — source de la distorsion observée.

Classe JavaBTEDymaxionProjection extends ConformalDynmaxionProjection ARC2 · arcsin(√((5 − √5) / 10)) ≈ 1.10714 rad VECTOR_SCALE_FACTOR1 / 1.1473979730192934 ≈ 0.87154 Grille SCconformal.lzma — 33 153 vecteurs (triangulaire 257×257), doubles big-endian Correction SCNewton-Raphson, 5 itérations sur champ de vecteurs interpolé barycentrement

La distorsion est une conséquence directe du fait que metersPerUnit() retourne une constante globale — le facteur d'échelle moyen sur l'ensemble de l'icosaèdre — alors que la transformation de Schwarz-Christoffel induit une variation locale continue du facteur d'échelle selon la position dans chaque face triangulaire.

metersPerUnit() = (40 075 017 / 2π) / VECTOR_SCALE_FACTOR = R / VECTOR_SCALE_FACTOR ≈ 7 318 262 m/unité

Cette valeur est utilisée comme conversion globale par le moteur de rendu. Elle est juste en moyenne sur l'ensemble de la projection mais incorrecte localement, produisant la distorsion observée dont la magnitude dépend de la position dans le triangle icosaédrique.

Pipeline de projection — fromGeo(λ, φ)

La chaîne de transformation complète depuis les coordonnées géodésiques WGS84 vers les coordonnées Minecraft :

① geo2Spherical(λ, φ) → (θ, colat) ∈ ℝ²
② spherical2Cartesian → vecteur unitaire sur S²
③ findTriangle(vec) → face ∈ {0…19} (centroïde le plus proche)
④ ROTATION_MATRICES[face] · vec → triangle de référence
⑤ triangleTransform (gnomonique) → projection plane sur la face
⑥ Newton-Raphson sur conformal.lzma → correction Schwarz-Christoffel (5 iter.)
⑦ FLIP_TRIANGLE + CENTER_MAP → placement dans le patron Airocean déplié
⑧ BTEDymaxion: rotation θ = −150°, swap axes → orientation Minecraft (X = Est, Z = Sud)
⑨ × 1000 → coordonnées blocs Minecraft (1 m = 1 bloc en théorie globale)

Indicatrice de Tissot — mesure de la distorsion locale

La méthode de Tissot calcule le tenseur métrique local de la projection en un point (λ, φ) par différences finies centrées. Pour une projection conforme, les deux facteurs d'échelle directionnels doivent être égaux.

h = √((∂x/∂φ)² + (∂y/∂φ)²) / R      [facteur méridien]
k = √((∂x/∂λ)² + (∂y/∂λ)²) / (cos φ · R)   [facteur parallèle]
sin t = |∂y/∂φ · ∂x/∂λ − ∂x/∂φ · ∂y/∂λ| / (R² cos φ · h · k)
σ_max = (h + k) / 2      σ_min = (h − k) / 2      [axes de l'ellipse de Tissot]
R utiliséTerraConstants.EARTH_CIRCUMFERENCE / (2π) = 6 378 137 m d (différentiel)10⁻⁷ radians ≈ 6.37 × 10⁻⁴ m — implémentation exacte de GeographicProjection.tissot() Conformité|h − k| / ((h+k)/2) → 0 si conforme ; distorsion angulaire = 2·arcsin((b'−a')/(b'+a')) → 0° ValidationMesure empirique sur 4 points in-game → k ≈ 1.054 ± 0.001 (Chambord)
